    B1 One file, every reader
    
          
    Spreadsheets deserve a source format.
    
          
    
            Markdown gave documents a format that works for people, tools, and Git.
            Spreadsheet data still bounces between binary workbooks, cloud services,
            CSV fragments, and Markdown tables. Marksheet is the missing source format.
          
    
          
    
            
    
              01
              
    People
    
              
    
                Open it in any editor. A handful of obvious constructs —
                @sheet, @table, @name — and the data
                itself, in pipe or CSV rows.
              
    
            
    
            
    
              02
              
    Git
    
              
    
                Change a number and the diff shows a number. Line-oriented blocks keep
                reviews focused, and marksheet diff compares meaning, not spelling.
              
    
            
    
            
    
              03
              
    Agents
    
              
    
                A small, deterministic grammar that is easy to generate and hard to
                misread, with a portable skill, a local tool server, and versioned JSON.

    D1 Review
    
            
    Reviews like code. Because it is.
    
            
    
              Raise the grocery budget, add a line item, nudge the tax rate. The pull request
              shows three edited rows, not a re-zipped binary.
            
    
            
    
              marksheet diff goes further: it compares the calculated workbook
              model, so reformatting is silent and real changes are named cell by cell.
              It exits 0 when two files mean the same thing, 1 when
              they don't — a ready-made CI gate.
            
    
          
    
          
    
            
            
          
    
        
    
      
    

      
    
        
    
          
    E1 The format
    
          
    A real workbook, in a few obvious lines.
    
          
    
            Marksheet keeps the parts of a spreadsheet that make it understandable, and
            leaves charts, validation and the rest to declarative extensions.
          
    
          
    
            
    
              
    Sparse sheets
    
              
    Place rectangular blocks at any A1 anchor. Empty cells cost nothing.
    
              
    @block F1 pipe
Setting|Value
Tax rate|0.2
@end
    
            
    
            
    
              
    Tables and fills
    
              
    Named tables with structured references, and one formula for a whole column.
    
              
    @fill costs[Subtotal] =[@Cost]*[@Quantity]
    
            
    
            
    
              
    Workbook names
    
              
    Readable formulas that refer forward, across sheets, to cells and tables.
    
              
    @name tax_rate = inputs!G2
@name cost_values = costs[Cost]
    
            
    
            
    
              
    Styles and geometry
    
              
    Reusable named styles, applied to ranges or table regions. Widths in familiar units.
    
              
    @style money number=currency currency="USD"
@apply costs[Cost] money
@column A width=18
    
            
    
            
    
              
    Deterministic calculation
    
              
    
                The portable-a1@1 profile has no clocks, randomness, I/O or
                network. Same file, same answer, everywhere.
              
    
            
    
            
    
              
    Lossless editing
    
              
    
                Edits are semantic transactions that return byte patches and exact inverses.
                Comments, spacing and spelling survive every save.
              
    
            
    
            
    
              
    XLSX and CSV conversion
    
              
    
                Deterministic import and export, with a report of what was exact,
                approximated, omitted or unsupported. Nothing disappears silently.
              
    
            
    
            
    
              
    Safe by construction
    
              
    
                Extensions are declarative. A workbook never selects, downloads or
                executes code; applications decide what they trust.
              
    
            
    
          
    
        
    
      
    

      
    
        
    
          
    
            
    F1 Built for agents
    
            
    The spreadsheet your agent can actually edit.
    
            
    
              No desktop automation, no cloud API, no reverse-engineered ZIP. An agent reads
              and writes Marksheet with ordinary file operations, and the CLI gives it
              precise, source-aware tools when it wants them.
            
    
            
      
              
    • A portable skill that teaches the format and its workflows.
      • 
              
    • A local tool server with a stable, checked JSON schema.
      • 
              
    • Harness profiles for Claude Code and Codex, proven on one task corpus.
      • 
              
    • Versioned JSON from get, set, calc and diff.

    H1 Get started
    
          
    Three commands to a calculated workbook.
    
          
      
            
    1. 
              
      Build the CLI
      
              
      git clone https://github.com/mattsoldo/marksheet
cd marksheet
cargo build --release -p marksheet-cli
      
            
      2. 
            
    2. 
              
      Write a workbook
      
              
      #!marksheet 0.1
@sheet main "Lunch"
@block A1 pipe
Item|Cost
Coffee|4.5
Bagel|3
Total|=SUM(B2:B3)
@end
      
            
      3. 
            
    3. 
              
      Check and calculate
      
              
      marksheet check lunch.ms
marksheet calc lunch.ms --sheet main \
  --range A1:B4 --format text
      
            
      4.
