# Security Policy

## Supported versions

Marksheet is currently **Draft 0.1**. Security fixes are made on the latest
development version; no release branches are supported yet.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Instead, use
GitHub's private vulnerability-reporting flow for this repository. If that
option is unavailable, contact the repository maintainers privately through
their GitHub profiles and include a link to the affected repository.

Provide a clear description of the issue, affected revision or command, steps
to reproduce, expected and actual behavior, and any suggested mitigation. Do
not include destructive proof-of-concept payloads or expose user data.

We will acknowledge a report as soon as practical, assess its impact, and work
with the reporter on a coordinated disclosure. This early project cannot
promise a response-time SLA, but reports will be handled in good faith.

## Scope

The scope includes the Rust reference implementation, command-line tool, and
repository automation maintained here. Security properties of third-party
tools, unpublished deployments, and future extensions are outside the current
support scope unless they directly affect this repository.
